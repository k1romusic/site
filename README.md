# K1RO — Music, Sound & Audio Technology

Официальный веб-сайт личного бренда **K1RO**: музыкальный продакшн, сведение, мастеринг, саунд-дизайн и авторские аудиоплагины (DSP).

## Стек технологий

- **React 19** + **TypeScript**
- **Vite 6** (быстрый HMR и сборка)
- **Tailwind CSS v4** (дизайн-система токенов K1RO Music)
- **Motion (`motion/react`)** (аппаратные пружинные анимации интерфейса)
- **Lenis** (плавный кинематографичный скролл с поддержкой тач-устройств)
- **Lucide Icons**
- **Локализация (i18n)**: двуязычная система (RU / EN) на базе типизированных словарей

---

## Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сайт откроется по адресу `http://localhost:5173`.

### 3. Production сборка
```bash
npm run build
```
Готовые статические файлы для деплоя будут скомпилированы в директорию `dist/`.

## Архитектура данных (Data-Driven)

Весь контент полностью отделен от разметки компонентов:

- **Плагины**: `src/data/plugins.ts` — чтобы добавить новый плагин, просто добавьте объект в массив `pluginsList`. Страница и карточки сгенерируются автоматически.
- **Работы и релизы**: `src/data/works.ts` — добавление новых треков, обложек и аудио-демо.
- **Услуги**: `src/data/services.ts` — список оказываемых услуг, этапы и результаты работы.
- **Загрузки**: `src/data/downloads.ts` — версионирование плагинов, выбор ОС (macOS / Windows), changelog и ссылки на инсталлеры.
- **Брендинг и контакты**: `src/data/brand.ts` — текст бегущей строки (Announcement), тезисы блока About, ссылки на соцсети.
- **Тексты интерфейса**: `src/i18n/ru.ts` и `src/i18n/en.ts`.

## Дизайн-система K1RO MUSIC

- **Background**: `#252422` (Глубокий темный графит)
- **Text**: `#F5F0E8` (Благородный кремовый off-white)
- **Accent**: Золотой градиент от `#FFC300` к `#b38800`
- **Typography**: `DM Sans`
- **Cards**: Премиальный Glassmorphism `bg-white/5 backdrop-blur-xl border border-white/10`

## Деплой на Cloudflare Pages

Сайт компилируется в чистый статический бандл:
1. Подключите репозиторий GitHub в панели Cloudflare Pages.
2. Build command: `npm run build`
3. Output directory: `dist`
4. Домены `k1ro.ru` и `k1ro.com` подключаются в настройках Custom Domains за 1 минуту.
